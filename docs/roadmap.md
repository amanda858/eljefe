# El Jefe Roadmap

## Phase 1: Frontend and positioning

1. Publish the marketing site, dashboard shell, and subscription flow
2. Finalize brand system, messaging, and paid conversion funnel
3. Add email capture and access requests for early users

## Phase 2: Commercial backbone

1. Add authentication
2. Add Stripe subscriptions and entitlements
3. Add account-level feature flags for Scout, Patron, and Jefe tiers

## Phase 3: Data foundation

1. Add sportsbook and exchange connectors for a limited set of sports
2. Normalize events, markets, books, and timestamps
3. Persist feed snapshots and event states

## Phase 4: Intelligence layer

1. Add vig removal and implied probability conversion
2. Add fair-price models per sport
3. Add EV ranking, alerting, and latency measurement

## Phase 5: Expansion

1. Add mobile notifications
2. Add API access for advanced subscribers
3. Add multi-seat and enterprise packages
